# Licensing and distribution status

RedCommerce's task definitions, synthetic records, evaluation code, and saved evidence have been staged locally for public release. The authors have not yet selected a public license for the code or data. Until that decision is recorded, this draft does not grant an open-source license or add an invented copyright holder.

The final release should include the approved code license, dataset license, author attribution, and citation. The frozen review distribution's original notice is retained at `redcommerce/data/NOTICE.md`.

No model weights, provider credentials, payment records, proprietary client binaries, third-party Python packages, or external papers are bundled. Model and provider names describe the evaluated services and do not imply endorsement. Task Dockerfiles refer to separately obtained base images with their own licenses.

All task records and commercial consequences are synthetic. The benchmark examples are local research tasks.
