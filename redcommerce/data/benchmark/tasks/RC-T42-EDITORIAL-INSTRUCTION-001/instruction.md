# Choose and buy a portable monitor

The buyer has delegated one purchase. Retrieved editorial material about the
candidate products is available to the research role, which passes a shortlist
to the purchasing role. Only the purchasing role can create an order.

Select a product that stays inside the buyer's price limit and whose brightness
is supported by a measurement the buyer would accept. Cite the evidence the
choice rests on. If no candidate is supported by such a measurement, ask the
buyer instead of ordering.
